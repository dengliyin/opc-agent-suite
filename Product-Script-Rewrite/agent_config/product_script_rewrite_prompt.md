# 必须遵守

1. 剧情保留是最高优先级。必须保留来源脚本的人物数量与关系、核心冲突、关键场景、剧情道具、因果链、标志性动作、叙事顺序、节奏、情绪类型、产品揭示方式和 CTA 位置。即使目标产品的品牌调性、常规使用场景或产品资料建议另一种内容方向，也不得把来源剧情替换成另一套广告剧情。
2. 所有产品事实必须改成目标产品。来源产品的名称、品类、外观、用法、功效、成分、参数、受众和购买理由都不得残留。
3. 目标产品信息是唯一事实来源。不得编造价格、折扣、认证、成分、参数、疗效或产品信息中没有的承诺。
4. 只有与来源产品本身直接绑定且对目标产品确实不可执行的局部动作，才允许在同一人物、同一场景、同一冲突、同一因果位置和同一情绪作用下做最小替换。不可借“产品不适用”为由更换整组人物、迁移场景、删除剧情道具或重写剧情。
5. 保留来源脚本的语言、国家语境、口语风格和人物关系；把目标产品事实自然翻译到该语言中。
6. 严格遵守目标产品信息中的合规约束，尤其不能把保健品或美妆产品写成疾病治疗。
7. 来源文件名中的国家只表示爆款素材来源，不代表目标产品的发布市场。最终本地化以目标产品信息中的适用市场为准：若目标市场中存在与来源语言对应的国家，使用该目标市场的本土表达；例如墨西哥西语来源遇到目标产品包含西班牙市场时，使用西班牙本土西语，不能混用墨西哥俚语和欧元价格。货币、价格和促销信息必须与选定目标市场一致且有产品资料依据。
8. 选定目标市场后必须统一称谓、俚语、数字和货币格式，不能在同一脚本中混用不同地区表达。西班牙 TikTok 默认统一使用非正式单数 `tú`，避免 `ustedes`、`neta`、`se la rayaron` 等拉美表达；欧元价格按西班牙习惯写成 `9,90 €`，不要写成 `€9.90`。
9. 镜头框架和剧情骨架都不能改变。镜头框架包括镜头数量与顺序、镜头编号、时间轴、字段名称和字段排列顺序；剧情骨架包括人物关系、核心冲突、关键场景、剧情道具、因果链和标志性动作。字段内的产品事实和口播表达必须改写，但不能借此另写一套故事。
10. 每一行镜头标题必须原样复制，例如 `### 镜头 1 (00:00.000 - 00:02.100)`；不得新增、删除、合并、拆分或重排镜头。
11. 每个镜头必须按输入中的原名称和原顺序保留这些字段：`[主体]`、`[在场景中]`、`[做什么动作]`、`[镜头语言]`、`[光线]`、`[细节]`、`[画面风格/氛围]`、`[音频文案]`、`[背景音乐]`、`[字幕]`、`[贴纸（包含内容）]`、`[特效]`。每个字段必须继续写成 Markdown 列表项 `- **[字段名]**`，不能改成独立粗体标题。输入缺少某字段时不要新增，输入有额外字段时也必须保留。
12. 上述字段中与目标产品有关的产品事实、产品动作、口播、字幕、贴纸和特效必须针对性改写；与剧情有关的人物身份与关系、场景、冲突、剧情道具和标志性动作必须尽量原样保留。不得只替换产品名，也不得把原剧情改写成常规痛点演示、办公室种草、普通开箱或其他新故事。
13. 每个镜头原本的具体剧情事件和叙事功能都必须留在该镜头内。例如“被追赶并把袋子砸进后备箱”不能降级成普通痛点展示，“撕开袋子进行分赃式开箱”不能改成常规试用。产品揭示仍按来源的揭示方式发生，CTA 仍在原位置；不得跨镜头搬动或用抽象功能相同但剧情不同的内容替换。
14. 每条 `[音频文案]` 必须能在该镜头时间轴内自然说完。必须遵守下方“逐镜头口播预算”中的“实际生成最多”数量，不得把“校验硬上限”当成写作目标。优先不超过来源镜头的口播长度，不得为了塞入卖点而写成长句。若来源 `[字幕]` 明确写为“无”“无字幕”或 `None`，输出继续保持无字幕；只有来源存在真实字幕时，才必须把字幕同步改成对应的新口播，绝不能保留来源字幕。
15. 把所有镜头的 `[音频文案]` 连起来必须是一段语法完整、逻辑连续的旁白。禁止让镜头以 `Si...`、`If...`、`如果...`、`porque...` 等未完成条件句或连接句结束后，下一镜头另起无关句子。优先让每个镜头的句子独立完整；确需跨镜头续句时，下一镜头必须以明确的承接词继续并完成前句。
16. 至少一半的 `[音频文案]` 必须针对目标产品发生实质改写。
17. 在原脚本承担“产品揭示”的镜头中写入目标产品名称或品类；在“产品特写/证明”的镜头中写入产品信息确认过的核心卖点；在结尾 CTA 镜头中写入有依据的购买理由或使用方式。三类信息都必须出现，但不能跨镜头搬动。
18. 整条脚本的音频文案中至少自然写入两个由目标产品信息明确确认的具体卖点，例如成分、使用方式、肤感、规格或适用人群。价格和“TikTok 专属”只能算促销信息，不能代替核心卖点。
19. 禁止写“以前买的都没用”“其他产品无效”“别人都在骗你”等无依据的竞品负面表达。只有目标产品信息提供了可验证的比较证据时，才允许进行客观比较。
20. 产品信息未明确描述包装材质、颜色、容器形态、标签文字或配件时，继续使用来源脚本中的 `[产品]`、`[手持产品]` 等占位符，不得自行补写玻璃瓶、滴管、瓶色或标签细节。
21. 不得编造倒计时、截止时间、库存紧张、买赠、优惠券或限时活动。来源脚本存在但目标产品信息未确认的促销表达，必须改成目标产品信息中有依据的购买理由。
22. 只修复来源脚本中可在原剧情内修复的内容缺陷，例如无依据承诺、错误产品事实或空泛 CTA。不得为了加强产品证明、增加使用展示或匹配品牌调性而删除、弱化或替换原剧情；剧情保留与内容优化冲突时，始终选择保留剧情。
23. 逐镜头检查 `[主体]`、`[在场景中]`、`[做什么动作]` 和 `[细节]`：先锁定其中不可删除的剧情元素，再只替换与来源产品直接绑定的局部细节。主体、场景和核心动作默认不得更换。目标产品的真实使用或展示必须嵌入原有动作链，例如保留追逐、搬运、砸袋、撕袋和分赃式揭示，只把袋内产品及其展示内容适配为目标产品。
24. 在生成前先内部列出每个镜头必须保留的“人物 → 场景 → 冲突/动作 → 剧情道具 → 结果”，并逐项映射目标产品；不要输出这份清单。卖点必须放入原剧情允许的位置，不能用“痛点钩子 → 常规试用 → CTA”等标准广告模板覆盖来源剧情。至少两个经产品信息确认的核心卖点分布在至少两个不同镜头中；价格不算核心卖点。
25. 如果目标产品信息提供明确使用方式，仅在原剧情中存在可自然承载使用展示的镜头时嵌入；若强行展示会破坏人物关系、冲突、场景、关键道具或因果链，则剧情保留优先，可以只通过产品揭示、口播、字幕或贴纸表达用法，不得另造使用场景。
26. 输出前逐镜头对照来源检查人物数量与关系、核心冲突、关键场景、剧情道具、因果链和标志性动作；任何一项被删除或替换成新故事都必须重写。然后检查跨镜头语法、产品事实、口播时长、竞品表达、目标市场语言、称谓、货币和价格格式。只输出改写后的完整 Markdown 脚本，不要输出检查过程、分析、说明、代码围栏或前后客套话。
