# OPC 资料库协作规则

本文件定义“AI+跨境电商 OPC 内容量化增长引擎”业务资料库的目录边界。Claude、Codex 和其他自动化 Agent 都必须遵守同一套路径，不得自行创建旧目录或平行目录。

## 资料库定位

- 当前文件所在目录就是资料库根目录。
- 程序通过 `OPC_VAULT_ROOT` 挂载资料库；不要在业务文件中写入某台电脑的绝对路径。
- GitHub 仓库只保存空目录模板和本文件，不保存真实产品资料、脚本、视频、音频或发布数据。
- 已有文件优先。初始化程序只补齐缺失目录和缺失的本文件，不覆盖用户修改。

## 纯 AI 视频线路

1. 9991 将爆款视频写入 `纯AI视频/01来源素材/<产品名>/`。
2. 9992 读取来源视频，将解析结果写入 `纯AI视频/02参考脚本/<产品名>/`。
3. 9993 读取参考脚本，将正式脚本写入 `纯AI视频/03产品脚本/<产品名>/`。
4. 9994 将正式脚本适配到 `纯AI视频/04适配脚本/<模型>/<产品名>/`。
5. 9995 将片段写入 `纯AI视频/05AI片段/<模型>/<产品名>/`，并把待合成任务导出到 `纯AI视频/06合成工作区/`。
6. 9998 合成后写入 `视频/成品视频/<产品名>/`，9996 在同一目录管理成品。

产品脚本改写和 AI 原创脚本也进入现有产品目录，通过统一文件名区分来源，不另外创建“爆款复刻”“改写”或“原创”顶层文件夹。

## AI 实拍混剪线路

1. 10001/10002 使用 `01参考视频` 和 `02解析脚本`。
2. 10003 将钩子与 CTA 复刻裂变稿写入 `03复刻裂变脚本/<类型>/<产品名>/`。
3. 9999 将适配结果写入 `04适配脚本/<模型>/<类型>/<产品名>/`。
4. 9995 将 AI 片段写入 `05AI片段/<模型>/<类型>/<产品名>/`。
5. 10004 将配音文件写入 `06音频文件/<产品名>/`。
6. 10000 从 `AI实拍混剪/07实拍素材/<产品名>/` 读取实拍素材，在 `AI实拍混剪/08混剪工作区/<产品名>/` 完成编排与输出。

## 文件和产品规则

- 产品事实以 `wiki/产品/产品信息/` 为准；产品参考图以 `wiki/产品/产品底图/` 为准。
- 业务目录从产品名开始分组。线路、来源、国家、语言和模型信息优先写进文件名或既定模型层级。
- 同一来源脚本的解析、产出、适配、片段和成品应保持可追溯的统一主文件名。
- 成品直接保存到 `成品视频/<产品名>/`，不要再按视频类型增加一层目录。
- 标题、正文和五个标签保存在 `成品视频/视频标题库/<产品名>.md`。
- 脚本纠错知识统一进入 `共享知识库/脚本错题本/`。

## 强制约束

- 不得回退到旧路径，也不得重新创建旧目录名称。
- 不得因某个 Agent 临时需要而新增资料库顶层目录；内部缓存和运行记录应存放在 Docker 数据目录，不进入业务资料库。
- 不得覆盖用户已有脚本、视频、音频、产品资料或本文件。
- 不得移动或删除业务文件，除非负责人明确授权并且已完成校验。
- 修改目录结构、命名规则或本文件前，必须先获得负责人确认，并同步更新 8888 全局路径、对应 Agent、空目录模板和测试。
