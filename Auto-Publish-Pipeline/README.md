# 10005 自动发布流水线

独立执行脚本裂变、脚本适配、片段产出、片段合成和串行发布。它复用现有 Agent 的底层命令入口，但不要求 9993–9995 的 Web 服务处于启动状态。

- 端口：`10005`
- 状态库：`data/pipeline.sqlite3`（本机文件，不提交）
- 发布配额：所选账号数 × 3
- 候选预算：发布配额 × 150%，向上取整（9 条发布配额会准备 14 条候选）
- 已有成品：10005 同脚本备用成片自动优先；手动 Agent 的同产品、同国家成片由用户确认后优先
- 失败容错：只要最终成功候选达到发布配额就继续，多余成片保留给后续任务
- 发布顺序：账号选择顺序，每个账号连续三条
- 发布间隔：上一条完成后 10 秒
