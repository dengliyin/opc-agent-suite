# AI＋实拍混剪智能体

- 端口：`10000`
- 独立目录、独立 Python 虚拟环境。
- AI 钩子和 CTA 只读取 `08混剪工作区/片段产出归档`；未导出的 `05AI片段` 不进入混剪素材池。
- 其他输入读取 `06音频文件`、`07实拍素材`。
- 中间产物和使用历史只写入 `08混剪工作区`。
- 成片统一写入共享的 `成品视频/<产品名>/`。
- CTA 为可选素材池；未开启时，成片在混剪音频与实拍中段结束。
- 钩子、混剪音频和所选 CTA 必须属于同一国家，国家代码从规范文件名中读取。
- 钩子、混剪音频和启用后的 CTA 均作为国家素材池自动轮换，不要求用户逐条选择。
- 每个钩子仅用于一条成功成片；成片数量自动等于尚未使用的钩子数量。
- 实拍素材使用自身完整时长，仅最后一个镜头可为对齐混剪音频结束点而裁短。
- 混剪音频可无限复用；每个实拍文件最多进入 100 条成功成片。
- 同一条成片内不重复实拍文件，且不得重复“同一混剪音频＋同一实拍素材顺序”。
- 不改写钩子、CTA 或混剪音频的内容。
- 去重处理支持手动多选或按成片随机组合；可使用画面变换、色彩、抽帧、镜像、轻微变速、边框、特效及编码变化。
- 去重处理不改变素材编排，也不处理钩子、CTA 或混剪音频。
- 字幕包装只提供一个“使用字幕”开关，固定使用 TikTok 卡拉 OK 逐词高亮样式。
- 字幕只对应混剪音频与实拍中段；钩子和 CTA 不加字幕。优先复用音频同名本地字幕，缺失时按所选国家语言用本地 Whisper 生成并保存，再按钩子时长偏移烧录。
- 使用 HyperFrames 完成最终渲染，FFmpeg 负责媒体探测、裁切和标准化。
