# AI＋实拍混剪智能体（10000）

独立完成以下三段式成片：

1. AI 钩子视频（保留原音频）
2. 产品介绍音频＋“展示/使用”实拍素材自动混剪
3. AI CTA 视频（保留原音频）

## 目录约定

```text
AI实拍混剪/
├── 05AI片段/<模型>/混剪-钩子/<产品名>/
├── 05AI片段/<模型>/混剪-CTA/<产品名>/
├── 06音频文件/<产品名>/
├── 07实拍素材/<产品名>/展示/
├── 07实拍素材/<产品名>/使用/
└── 08混剪工作区/<产品名>/

成品视频/<产品名>/AI实拍混剪-*.mp4
```

## 处理原则

- 中段长度严格跟随产品介绍音频，不拉长或改写音频。
- 展示与使用镜头交替编排，优先使用历史次数较低的素材。
- 每条成片记录素材路线签名，生成多条时尽量避免重复路线。
- “原创差异处理”包含切片入点、镜头顺序、轻微裁切/缩放和色彩差异。
- AI 钩子/CTA 若带技术性尾部黑屏静音，会自动识别并裁掉，不把技术填充带入成片。
- 所有成片均经过视频流、音频流和时长校验，并生成同名 `.metadata.json`。

## 启动与测试

```bash
python3 -m venv .venv
./scripts/validate_app.sh
./scripts/start_web.sh
```

打开：`http://127.0.0.1:10000/`
