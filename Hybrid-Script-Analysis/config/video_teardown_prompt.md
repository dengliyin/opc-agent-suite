【核心限制】

一、强制时间切分与重置：必须将原视频时间码务必精确到毫秒（MM:SS.mmm）。


二、禁止使用代词：在描写 [主体] 时，只要画面中出现了核心人物，严禁单独使用“他”、“她”、“主角”、“那个男人”等代词。

三、强制全貌复述：

无论该人物在视频的第几秒出现，你都必须在 [主体] 栏位中重新完整填写该人物的标准视觉特征。

执行标准： 每次必须包含 [具体年龄/性别] + [肤色/发型/五官特征] + [上衣具体款式与颜色] + [下装具体款式与颜色]。即使是背影，也要复述衣着特征。

【核心限制：产品描述强制清洗】

(此规则是为了适配 Veo 的 Image-to-Video 功能，避免文本与垫图冲突)

# 先判断“真实带货商品”，再决定是否清洗：

必须先根据视频标题、口播、字幕、CTA、展示顺序、使用场景判断本条视频真正要卖的商品是什么。

只有“真实带货商品”才允许替换为“[产品]”或“[手持产品]”。

不要把以下内容替换成“[产品]”：

- 痛点道具：手机、自拍杆、旧物、坏掉的物品、对比用物品。
- 场景工具：桌子、支架、包装箱、货架、镜子、花洒、清洁工具。
- 拍摄设备：手机、相机、三脚架、自拍杆、稳定器。
- 故事道具：被摔坏的手机、脏衣服、破损物、普通生活物品。
- 不是被推荐购买的物体，即使被人物手持，也不能自动视为产品。

这些非带货商品必须保留真实类别名称，但不要展开过多品牌/外观细节。例如写“手机”“自拍杆”“手机支架”“破损手机屏幕”，不要写成“[产品]”。

判断标准：如果后续脚本生成时会用用户上传的商品参考图替换它，它才是“[产品]”；如果替换后会让剧情逻辑错误，它就不是“[产品]”。

# 触发条件：

当原视频画面中出现真实带货商品时，触发本规则。仅仅“主体手中拿着物体”不能触发本规则。

# 执行动作：

视觉忽略：绝对禁止描述原视频中产品的任何视觉特征（如颜色、形状、材质、包装袋、瓶装、文字等）。

强制替换：必须统一将产品指代为“[产品]”或“[手持产品]”。

目的：提示词将配合 Veo 的图像控制功能使用，画面的产品特征完全由我上传的参考图决定，文本描述不得产生干扰。

# 错误示范（禁止）：

❌ [主体] ...手持一个黑色的袋装护发素... (错误：描述了颜色和包装)

❌ [主体] ...拿着带有金色文字的瓶子... (错误：描述了细节)

# 正确示范（必须）：

✅ [主体] ...手持[产品]... (正确：仅描述动作关系)

✅ [主体] ...举起[产品]展示... (正确：让参考图控制外观)

# 反例修正：

如果视频卖的是无人机，但开头剧情里手机从自拍杆上掉落并摔坏：

✅ 正确写法：手机从自拍杆夹口脱落、手机屏幕摔碎、男性因手机损坏而崩溃。

❌ 错误写法：[产品]从自拍杆夹口脱落、[产品]屏幕摔碎。

因为真实带货商品是无人机，手机只是痛点道具，不能替换为“[产品]”。
