# 科赛力量爆款视频拆解知识库 v1

整理日期：2026-05-14

来源范围：`knowledge/00-知识库总整理.md`、`knowledge/01-实战调用手册.md`、`knowledge/frameworks.md`、`knowledge/tk-strategy.md`、`knowledge/_tk_extracted/` 中与 TikTok 电商短视频拆解、素材框架、原生感、转化逻辑相关的内容。

使用边界：本知识库只用于“拆解竞品/爆款视频为什么能跑、为什么能转化”。不要在这个阶段调用产品档案，不要替用户生成自家产品脚本。后续“仿写脚本”阶段再结合产品信息。

统一占位：分析产品展示、产品动作、产品包装、产品机制时，统一使用 `[product]`。

---

## 1. 拆解目标

拆解视频时，不要停留在“画面好不好看”或“文案有没有吸引力”。必须反推这条视频的商业机制：

- 它在开头捞的是哪类人。
- 它用什么生活瞬间、痛点、反差或情绪让这类人停下。
- 它的卖点是在什么观看状态下自然出现的。
- 它如何让 `[product]` 像一个顺手出现的解决方案，而不是硬塞广告。
- 用户可能在哪个瞬间完成“我想买”的心理转折。
- 它属于已有素材类型，还是沉淀出了新的可复用素材类型。

核心判断顺序：

```text
人群 -> 开头筛选 -> 结构递进 -> 原生感信任 -> 卖点出现顺序 -> CTA/价格锚点 -> 可复用框架
```

---

## 2. 反广告感判断标准

很多视频不是卖点不够，而是“状态”像广告。拆解时必须判断：

1. 如果不卖 `[product]`，这条视频是否仍然成立？
   - 成立：它可能是内容，例如吐槽、生活问题、实验、对比、评论答疑、真实复购。
   - 不成立：大概率只是广告。
2. 它是在讲给一个具体人群，还是对所有人喊话？
   - 好视频通常很偏心，例如懒人、白发困扰者、DIY 新手、预算有限但想变好的人。
3. 开头第一反应是表达，还是展示？
   - 表达：问题、情绪、反差、警告、悬念。
   - 展示：直接亮产品、堆卖点、促销喊单。

正确路径：

```text
真实问题/生活场景/情绪表达 -> [product] 顺带出现 -> 信任形成 -> CTA
```

错误路径：

```text
产品展示 -> 卖点堆叠 -> 促销逼单
```

## 3. 爆款内容三层

### 3.1 人群层

先判断视频到底在和谁说话。一个产品可以有多个卖点，每个卖点背后是不同人群。拆解时必须输出：

- 显性人群：画面和文案明确叫到的人。
- 隐性人群：没有直接说，但会被痛点击中的人。
- 生活状态：对方当时为什么愿意停留。
- 购买动因：省事、省钱、变美、避坑、被理解、降低决策风险等。

### 3.2 结构层

开头不是为了留住所有人，而是筛出对的人。拆解时重点判断：

- 前 3 秒用的是警告、吐槽、实验、对比、评论问题、视觉奇观、关系冲突，还是反常识？
- 中段每个镜头是否在推进信息，而不是重复展示。
- 卖点出现前，是否已经让用户代入痛点。
- 结尾是否自然完成价格锚点、稀缺、低风险承诺或行动指令。

### 3.3 原生感层

原生感不是高级，而是不违和。拆解画面时必须看：

- 场景是否像目标市场真实生活，而不是被设计过的棚拍。
- 光线是否自然，镜头是否过稳、过干净、过专业。
- 道具、桌面、背景、服装、人物动作是否合理。
- `[product]` 是否像使用过程中顺手出现，而不是为展示而展示。
- 节奏是否通过小动作、角度变化、功能拆分持续推进。

## 4. 逐帧拆解要求

必须按实际镜头切换点拆，不按固定秒数硬切。

标准表头：

| Shot ID | 时间码(MM:SS.mmm) | 画面全息描述(景别/运镜/场景/人物动作/贴图) | 原音逐字脚本 | 中文翻译 | 情绪与语调(Tone) |
|---|---|---|---|---|---|

画面全息描述至少包含：

- 景别：远景/中景/近景/特写/极近特写/屏幕录制/分屏。
- 运镜：手持、推近、拉远、平移、俯拍、跟拍、固定机位、快速切换。
- 场景：厨房、浴室、卧室、车内、梳妆台、办公室、户外、直播间等。
- 人物动作：吐槽、试用、对比、指向购物车、展示结果、回购展示。
- 贴图/字幕/评论：如果画面上有关键文字，必须记录。
- `[product]` 出现方式：首次出现时间、是否已拆封、是否正在被真实使用。

音频规则：

- 有人声时，先逐字转录；非中文内容必须给地道中文翻译。
- 听不清时标注“听不清”，不能编造。
- 无人声但有字幕时，逐字记录字幕。
- 无人声无字幕时，用画面动作和节奏做判断，并说明依据。

## 5. 26 种素材类型索引

拆解时先尝试命中下列素材类型。编号必须沿用原始框架库编号，不能按分组重新编号。若命中，必须写出“类型编号 + 类型名称 + 命中证据”；若没有充分证据，不要强行套入既有类型，应基于底层逻辑命名新类型。

### 原始编号清单

1. 警告冲突式：用警告、风险感、反常识快速抓注意力。
2. 委屈型：替用户说出长期被忽略或被行业折磨的委屈。
3. 意外起因型：用“一不小心发现”制造自然探索感。
4. 纯内容池（不要 XX 要 XX）：避坑清单、参数清单、选购指南，高信息密度。
5. 暴露缺点式：先主动承认缺点，再筛选真正适合的人。
6. 硬广式：行业乱象、品牌立场、自己为什么这样做。
7. 利己式：从自己踩坑、个人标准、主理人视角切入。
8. 反教知识素材：打破用户对品类的浅层认知。
9. 四项积木法：用期望、焦虑、怀念、遗憾驱动情绪。
10. 揭秘式：大众以为 vs 现实真相，适合避雷科普。
11. 连续否定式：连续错误做法制造紧张感。
12. 关系场景式：家庭、情侣、朋友、社交关系中放大痛点。
13. 行业丑闻/关系冲突：对话体揭露行业敷衍解决方案。
14. 读心式困惑：帮用户说出“如果不是因为这个问题，谁愿意这样”的真实困惑。
15. 认知错误强钩子：先别买/先别用，制造“我是不是用错了”的担心。
16. 连续制造意外事件：连续反转、猎奇测试、结果不断超预期。必须是多个意外事件递进，不是单一极端演示。
17. 专家背书型：药剂师、实验室、白大褂、半专业术语等专业身份建立信任。
18. 视觉诊断型：症状/痛点对号入座，用户会想看自己是否命中。
19. 内容池 + 意外起因：高密度信息与探索发现结合，常见于参数、测试、细节堆料。
20. 专家背书 + 视觉诊断：科学化焦虑，再给低门槛解法。
21. 社交分屏降维式：朋友对比、大牌 vs 平价、价格反转。
22. 三阶对比淘汰式：A/B/C 分级对比，C 必须有视觉碾压。
23. 痛点暴击与利益逼单：快准狠痛点 + 大容量/低单价/低风险承诺。
24. 视觉自证与权威背书：仪器、证书、检测报告、客观实测反应等三环信任。只有普通手持演示时，不要轻易归入此类。
25. 真实复购自证式：空瓶、新瓶、已拆封包装、自己回购。
26. 互动答疑式专业种草：真实评论问题切入，像非利益相关的专业答疑。

### 快速分组

- 留人和完播优先：3、4、15、16、18、19。
- 信任建立优先：5、6、7、10、17、24、25、26。
- 强转化和逼单优先：1、2、11、12、13、14、21、22、23。
- 复合型：20，以及视频中真实同时存在的跨类型组合。

## 6. 框架匹配方法

匹配素材类型时，不要只看文案模板，要看底层机制：

- 开头机制：警告、吐槽、评论、实验、对比、诊断、关系冲突、反常识。
- 信任机制：原生场景、复购、专业身份、物理实测、社会证明、缺点自曝。
- 转化机制：低试错成本、价格反转、库存稀缺、限时补贴、货到付款、强指令。
- 画面机制：分屏、手持、特写、实测、空瓶、前后对比、购物车指向。
- 人群机制：谁会因为这个痛点停下，谁不会被这条视频打动。

如果多个类型同时命中，优先选择主导观看心理的类型。例如评论答疑里夹了价格逼单，主类型仍可能是互动答疑；社交对比里有强促销，主类型仍可能是社交分屏降维。

强制校准规则：

- 不能因为视频“有视觉证明”就归为类型24。类型24 必须有仪器、证书、检测报告、客观测试装置或权威背书；单纯手持涂抹、揉搓、试用，更可能是新类型或其他类型。
- 不能因为视频“有意外动作”就归为类型16。类型16 必须至少有 3 个以上不同事件按 A -> B -> C 递进，并且每一次都带来新反转；同一个测试动作的升级版（例如从胡子涂到脸、从手涂到全脸）不算连续制造意外，只能算极端压力测试。
- 如果视频核心是“把 `[product]` 用在用户认为危险/错误/会翻车的地方，然后证明没有翻车”，优先考虑沉淀为新类型：极端暴力自证式、反直觉压力测试式、禁忌动作自证式等。
- 输出框架匹配时必须三选一：
  1. 精准命中已有框架：写“命中类型 X：名称”，并给证据。
  2. 只与已有框架有局部相似：写“部分相似于类型 X，但不构成命中”，并说明差异。
  3. 未命中已有框架：写“未精确命中已有 26 类，应沉淀新素材类型”。
- “部分相似”不得写成“命中变体”。不要为了使用知识库而硬套既有框架。

## 7. 转化逻辑剖析清单

每条视频拆解后必须回答：

1. 人群筛选：开头捞谁？使用了什么生活困扰、情绪或场景？
2. 需求激活：用户为什么会继续看？是焦虑、好奇、共鸣、避坑还是视觉爽感？
3. 卖点出现顺序：卖点是先讲、后讲，还是通过画面让用户自己意识到？
4. 信任构建：原生感、专业背书、社会证明、物理实证分别在哪里出现？
5. 逼单时机：价格、优惠、稀缺、低风险承诺在第几秒进入？
6. 成交瞬间：最可能让用户想买的镜头或句子是哪一个？
7. 风险点：是否过度夸大、医疗化、参数虚标、价格无依据、字幕与画面冲突？

## 8. GMV Max 和素材复盘视角

拆已经跑起来的视频，不是为了复述它长什么样，而是拆它为什么能跑：

- 开头是否足够地道，是否像目标市场用户真实表达。
- 开头到底在捞显性需求，还是潜在需求。
- 卖点顺序是否符合购买动机。
- 场景、道具、光线、节奏为什么不像广告。
- 用户在哪个瞬间完成“我想买”。

新素材不消耗的常见根因：

- 只换文案和镜头，底层人群没变。
- 只换画面，结构逻辑还是老素材。
- 播放有但不转化，开头没有筛对人。
- 素材越堆越乱，一轮里同时改了人群、卖点、场景和剪辑。

复刻不是换词重拍。真正可复用的变化包括：

- 同样开头，换卖点优先级。
- 同样卖点，换使用场景。
- 同样人群，换更贴近生活的切入点。
- 同样框架，换信任证据或 CTA 方式。

## 9. 新素材类型沉淀规则

如果视频不属于已知 26 种素材类型，必须沉淀新类型。新类型要能给拍摄团队直接执行，不能只是抽象名字。

输出结构：

```markdown
**新素材类型名称：[命名]**

* **素材开头 (Hook: 前3秒)**
  * 画面结构 (Visual)：景别、场景、人物破冰动作、视觉奇观/贴图样式。
  * 文案结构 (Audio)：情绪底色、话术公式、可填空句式。

* **素材中间 (Body: 信任构建与欲望拉升)**
  * 画面结构 (Visual)：动作、背书、产品机制特写、对比镜头。
  * 文案结构 (Audio)：拉踩/反直觉逻辑、核心解法、证据链。

* **素材结尾 (End: 逼单与转化)**
  * 画面结构 (Visual)：指向购物车、闪回、价格贴图、库存提示。
  * 文案结构 (Audio)：算账逻辑、FOMO、低风险承诺、行动指令。

* **素材框架核心 (Core)**
  * 一句话总结底层洗脑与转化逻辑。
```

## 10. 输出约束

- 事实和推断分开写。画面里看得到、听得到的才是事实；人群、心理、转化逻辑属于推断，必须说明依据。
- 不要编造视频中没有出现的数据、价格、折扣、品牌背书。
- 不要因为视频里有 `[product]` 就默认是硬广，要判断它是否像内容。
- 不要把所有视频都套进现成 26 类。无法准确匹配时，必须命名新素材类型。
- 非中文视频先转录和翻译，再做结构分析。
- 所有产品称呼统一泛化为 `[product]`。
