拆解这个视频。参考这个视频的视频画面和文案，每一个镜头都要拆解分析出来成由：[主体] + [在场景中] + [做什么动作] + [镜头语言] + [光线] + [细节] + [风格/氛围] + [音频文案] + [背景音乐] + [字幕] + [贴纸（包含内容）] 结构的提示词。特效信息统一写入 [细节]。除真实带货商品的外观细节必须按下方规则清洗外，其余人物、场景、动作、镜头和视听信息都要便于我在使用 AI 复刻视频时一比一还原对标视频。



【人物视觉指纹与一致性铁律（优先级最高）】

一、先建档，再拆解镜头

分析镜头前，必须先遍历全片，选择人物正脸最清晰、无遮挡、光线正常的一帧作为人物识别基准，在内部建立固定的“人物标准视觉档案”。

同一人物每次出现在镜头中时，[主体] 必须逐字复用同一份标准视觉档案。禁止因表情、角度、远近、光线或局部遮挡而改变人物的年龄、脸型、肤色、五官、发型、服装和标志性特征。

不要把不同角度下的同一人物误判为不同人物。多人视频应分别建立“人物 A”“人物 B”等独立档案。

二、禁止使用代词或宽泛审美词代替人物特征

在 [主体] 中禁止单独使用“他”“她”“主角”“那个男人”“美女”“年轻女性”“外国女性”“网红脸”等宽泛表述。

“漂亮、精致、帅气、甜美、高级”等评价词不能替代可观察的几何特征。

三、人物标准视觉档案必须按以下顺序完整描述

1. [年龄与性别呈现]
使用可见年龄区间，例如“约 28—32 岁的成年女性”，不要虚构精确年龄。

2. [肤色]
必须包含肤色深浅和冷暖倾向，例如“暖调白皙肤色”“中等深度橄榄色肤色”。

3. [脸型与面部比例]
必须描述脸型宽窄、长度、额头高度、颧骨、下颌线和下巴形状。例如：“偏长窄的椭圆脸，额头较高，颧骨清晰，下颌线向下收窄，下巴尖中带圆。”

4. [眉毛]
必须描述颜色、粗细、浓密度、走向和眉峰高低。例如：“深棕色粗浓眉毛，整体接近平直，眉峰较低。”

5. [眼睛]
必须描述虹膜颜色、眼睛大小、形状、眼距和睁眼状态。例如：“浅蓝灰色大眼睛，睁大时接近圆形，眼距中等，不是细长杏仁眼。”

6. [鼻子]
必须描述鼻梁宽窄、长短、走势和鼻尖形状。例如：“鼻梁窄而笔直、长度中等，鼻尖小巧。”

7. [嘴唇与牙齿]
必须描述嘴唇厚薄、宽度、唇色；牙齿只有在清晰可见时才描述。

8. [标志性特征]
必须记录能够区分身份的痣、雀斑、酒窝、疤痕、面部不对称或其他稳定特征，并说明准确位置。没有清晰证据时写“未观察到明确标志性特征”。

9. [头发]
不得只写“棕色长发”或“金色卷发”。必须分别描述发根颜色、主体发色、挑染位置、分缝方式、长度、顺直或卷曲程度、发量和发尾状态。例如：“深巧克力棕色胸部长度长发，中间分缝，发根保持深棕色，仅面部两侧有少量细窄焦糖色挑染；整体顺直光滑，发尾轻微自然弯曲，不是浅金色大波浪。”

10. [妆容]
必须分别描述眼妆、睫毛、腮红位置和颜色、唇妆及皮肤质感。例如：“纤长黑色睫毛、轻微眼线、颧骨与鼻梁两侧带暖珊瑚粉腮红、自然裸粉色唇妆。”

11. [服装]
必须描述实际可见的上衣款式、领型、材质、颜色及贴合程度；下装只有在视频中真实可见时才描述。未入镜的服装必须写：“下装未入镜，无法判断，复刻时保持不入镜。”禁止为了满足格式而虚构裤子、裙子或鞋子。

12. [配饰与手部]
描述实际可见的耳饰、项链、眼镜、美甲形状、长度和颜色。产品仍遵守“真实带货商品识别与产品描述清洗”规则。

四、不可见信息处理

任何被手掌、产品、头发或画面边缘遮挡的特征，都必须结合全片其他清晰画面判断。

如果全片始终不可见，必须明确写“未入镜或无法判断，复刻时保持不入镜”，严禁猜测或自行补全。

禁止从人物外貌推断国籍、职业、身份或性格。国家代码只能依据语言、字幕、货币、地名和账号等明确线索判断。

五、表情与动作不得污染固定身份档案

人物的脸型、五官、发型和服装属于固定身份特征，写入 [主体]。

当前镜头中的睁眼、眨眼、张嘴、微笑、挑眉、转头、手势和身体动作写入 [做什么动作]。

近距离广角造成的脸部、眼睛或手掌放大属于镜头透视，写入 [镜头语言]，不得误写成人物固有特征。

六、人物镜头还原规则

只要人物是主要视觉主体，[镜头语言] 必须同时包含：

- 手机前置或后置摄像头、专业相机等拍摄设备类型；
- 特写、胸像、中近景、半身或全身景别；
- 镜头与人物面部的大致距离；
- 平视、俯拍或仰拍角度；
- 等效广角、标准或长焦透视；
- 头顶留白和画面下方裁切位置；
- 人脸在画面中的面积与位置；
- 手掌或产品是否靠近镜头以及产生的近大远小关系；
- 对焦主体、背景虚化程度和自动对焦变化；
- 固定机位、手持微抖、构图漂移或稳定运镜。

禁止把近距离手机自拍拆解成远距离坐姿人像，也禁止遗漏前景手掌对人物面部产生的透视影响。

七、输出前强制自检

输出每个 [主体] 前必须检查：

1. 同一人物的固定视觉档案是否逐字一致；
2. 是否把深棕发错误写成浅金发；
3. 是否把顺直发错误写成蓬松大波浪；
4. 是否遗漏脸型、眉毛、眼睛、鼻子、嘴唇或标志性特征；
5. 是否虚构了未入镜的下装或鞋子；
6. 是否用“美女、网红脸、精致”等评价词代替可观察特征；
7. 是否遗漏自拍距离、广角透视、裁切范围和前景手掌比例；
8. 描述是否足以让不了解原视频的人区分该人物与普通模板人物。

【真实带货商品识别与产品描述清洗】

为了配合 Image-to-Video（图生视频）模式，避免文字描述与我上传的产品参考图发生冲突，必须先判断“真实带货商品”，再决定是否替换：

必须根据视频标题、口播、字幕、CTA、展示顺序和使用场景，判断本条视频真正要卖的商品是什么。

只有真实带货商品才允许替换为“[产品]”或“[手持产品]”。仅仅因为某个物体被人物手持，不能将其判断为真实带货商品。

以下非带货商品不得替换为“[产品]”或“[手持产品]”：

- 痛点道具：手机、自拍杆、旧物、坏掉的物品、对比用物品。
- 场景工具：桌子、支架、包装箱、货架、镜子、花洒、清洁工具。
- 拍摄设备：手机、相机、三脚架、自拍杆、稳定器。
- 故事道具：被摔坏的手机、脏衣服、破损物、普通生活物品。
- 不是被推荐购买的物体，即使被人物手持，也不能自动视为产品。

这些非带货商品必须保留真实类别名称，但不要展开过多品牌或外观细节。例如写“手机”“自拍杆”“手机支架”“破损手机屏幕”，不要写成“[产品]”。

判断标准：如果后续脚本生成时会用用户上传的商品参考图替换它，它才是“[产品]”；如果替换后会让剧情逻辑错误，它就不是“[产品]”。

当原视频画面中出现真实带货商品时，绝对禁止描述该商品的颜色、形状、材质、包装、包装文字和花纹等视觉特征，必须统一将其写为“[产品]”或“[手持产品]”。

本清洗规则的优先级高于“一比一还原”，并且覆盖所有视觉描述字段，包括 [主体]、[在场景中]、[做什么动作]、[镜头语言]、[光线]、[细节] 和 [风格/氛围]。不得在任何字段中通过补充说明、括号、比喻或侧面描述重新写回真实带货商品的品牌、品类、型号、颜色、形状、尺寸、材质、纹理、包装、Logo、图案或包装文字。

允许保留的只有真实带货商品的数量、空间位置、与人物或道具的关系、人物对它执行的动作、使用方式、运动方向、使用结果，以及它在画面中的构图比例、远近、遮挡和对焦关系；商品本体仍只能写为“[产品]”或“[手持产品]”。

[音频文案] 必须保留原视频实际说出的内容。[字幕] 和 [贴纸] 只记录视频后期叠加在画面上的真实内容；产品包装本身印刷的文字、Logo 和图案不属于字幕或贴纸，不得转写到这两个字段。

【产品清洗输出前自检】

输出每个镜头前必须检查：

1. 是否先正确识别了真实带货商品，而没有把手机、自拍杆、拍摄设备、场景工具、痛点道具或故事道具误替换为 [产品]；
2. 所有视觉描述字段中的真实带货商品是否只写为 [产品] 或 [手持产品]；
3. 是否在任意字段中泄漏了真实带货商品的品牌、品类、型号、颜色、形状、尺寸、材质、纹理、包装、Logo、图案或包装文字；
4. [字幕] 和 [贴纸] 是否只记录后期叠加内容，而没有误收录产品包装上的印刷信息。
