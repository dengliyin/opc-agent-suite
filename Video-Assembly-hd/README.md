# 片段合成智能体

独立、完全离线的产品视频片段扫描与拼接工具。

## 启动

```bash
bash scripts/start_web.sh
```

访问 `http://127.0.0.1:9998/`。

## 工作流

页面扫描以下目录：

```text
$OPC_VAULT_ROOT/wiki/视频/视频片段 （待拼接）
```

扫描结果分为已有成品、待拼接、已归档和异常。“待拼接”项目可以选择后拼接；“已有成品”中仍保留源素材的项目可以选择后清理。两个操作都需要独立的二次确认，扫描和拼接完成都不会自动删除素材。

右侧运行面板常驻显示文字贴纸设置，默认关闭；成品文件列表不在页面展示。选中同一产品的待拼接项目后，可以按“产品 + 销售国家”读取 `wiki/视频/视频文字标签贴纸库`中的本地 Markdown 预设，选中后回填贴纸文字并显示中文释义；也可继续手动输入。“随机分配”会在当前产品和国家的文案池内，为批量中每个成品单独分配文案；预设数量足够时不重复，用完一轮后才重新随机。字体、位置和时间在同一批次中保持一致。初始提供“粗体衬线”、“气泡卡通”、“TikTok Sans”和“电影字幕”四种风格，可选上方、中部或下方安全位置，以及全片或自定义显示时间。贴纸最多 36 个字符、最多两行，会自动调整字号并使用轻量进出场动画。字幕仍保持关闭。

成品输出到：

```text
$OPC_VAULT_ROOT/wiki/视频/成品视频/产品/脚本同名.mp4
```

扫描时仍会识别旧的 `成品视频/模型/日期/产品/脚本同名.mp4`，但新拼接的视频只写入新结构。

## Agent 职责

- 视频产出 Agent 负责生成片段、图片并导出到待拼接目录。
- 片段合成 Agent 负责扫描、拼接、成品校验和已拼接素材清理。
- 清理前使用 FFprobe 确认成品有有效时长、视频轨和音频轨，并要求用户勾选“成品可以使用”。
- 清理仅删除待拼接脚本目录中的片段、图片和 `.product-lock.json`；保留 Markdown、`.exported.json` 和成品 MP4。
- 清理后导出记录写入 `upload_status: "已清理"` 和 `media_cleaned: true`。

## 离线边界

- 不调用远程模型或 API。
- 页面不加载 CDN、远程字体或远程图片。
- 不通过 `npx`、`pnpm dlx` 或包管理器下载运行依赖。
- Node、FFmpeg、FFprobe、HyperFrames、Chrome 和 GSAP 均由本目录提供。
- HyperFrames 的更新检查、自动安装和遥测均关闭。
- 贴纸配置保存在本地 `data/latest-scan.json`，不会在待拼接素材目录中新增配置文件。
