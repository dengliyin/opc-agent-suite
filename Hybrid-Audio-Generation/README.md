# 配音智能体（10004）

把本地 Markdown 音频文案转换为 AI＋实拍混剪可直接读取的 M4A 音频。

## 输入格式

```markdown
## 西班牙 ES

### ES-001｜高空拍摄

建议音频文件名：`AI音频-ES-高空拍摄-001.m4a`

音频文案：

> 需要配音的原语言文案。

中文校对：

> 仅用于人工校对，不会送入配音。
```

## 输入与输出

```text
AI实拍混剪/
├── 06音频文案/<产品名>-原创文案.md
└── 06音频文件/<产品名>/AI音频-<国家>-<主题>-<编号>.m4a
```

## 启动

```bash
./scripts/start_web.sh
```

打开：`http://127.0.0.1:10004/`
